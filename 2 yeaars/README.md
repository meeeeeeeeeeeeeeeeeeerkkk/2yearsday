# Два года вместе ❤️

Статический сайт для GitHub Pages. Не требует сборки, Node.js или сторонних библиотек.

## Как опубликовать на GitHub Pages
1. Создайте новый репозиторий на GitHub (например, `anniversary-site`).
2. Распакуйте архив и загрузите **содержимое** папки в корень репозитория: `index.html`, `style.css`, `script.js`, папку `assets`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, branch `main`, folder `/(root)`, нажмите **Save**.
5. Через минуту сайт будет доступен по адресу вида `https://ВАШ-ЛОГИН.github.io/anniversary-site/`.

## Как поменять текст или фото
- Поздравление и письмо: редактируйте `index.html`.
- Цвета и оформление: `style.css`.
- Фото: замените `assets/nasha-foto.jpg`, оставив такое же имя файла.
- Сайт рассчитан на телефоны и компьютеры; анимации лёгкие, сторонних скриптов нет.

Шрифты подгружаются из Google Fonts, но если они недоступны, включатся системные запасные шрифты.
